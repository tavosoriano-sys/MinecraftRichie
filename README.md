# Ricardo cumple 9

Invitación móvil y tarjeta PNG de 1080 × 1600. Se conserva la imagen del HTML proporcionado.

## Publicar
En Settings → Pages, selecciona Deploy from a branch, rama main, carpeta /(root), y guarda. La URL esperada es https://tavosoriano-sys.github.io/MinecraftRichie/ . Espera a que GitHub confirme la publicación.

## Confirmaciones
El formulario abre WhatsApp a +52 55 5215 1188 con nombre, respuesta y cantidad total de personas. El invitado debe pulsar Enviar. No se almacena una lista ni se confirma asistencia por abrir el chat. Las notificaciones dependen de la configuración de WhatsApp del receptor. No hay claves ni servicios de pago.

## Datos
Datos del ejemplo: Ricardo, 9 años, 12 de diciembre a las 15:00, ubicación de Google Maps. Se asume 2026 y zona America/Mexico_City; validar antes de distribuir. El calendario usa 21:00 UTC. Para cambiar datos, actualizar HTML, calendario y PNG. No publicar datos adicionales de menores.

Comparte invitacion.png junto con la URL: una imagen por sí sola no contiene botones interactivos.
